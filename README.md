# StringsVectorsAndDictionaries



\# Лабораторная работа № 5

\## Вариант 22 — Строки, векторы и словари



Программы написаны на C++. Каждая часть запускается отдельно.

Букву части вводить не нужно.



\### Задачи и ввод

\- A.cpp — вывод слов с заглавной латинской буквы.

&#x20; Ввод: строка длиной до 200 символов ASCII.

\- B.cpp — сортировка чисел по неубыванию.

&#x20; Ввод: количество чисел n, затем n целых чисел.

\- C.cpp — отбор пар словаря со значением не меньше порога.

&#x20; Ввод: количество пар, пары «ключ число», затем порог.

&#x20; При повторении ключа сохраняется последнее значение.

\- D.cpp — вывод отправителей и длины сообщений длиннее 20 символов.

&#x20; Ввод: количество записей, затем отправитель и текст каждой

&#x20; записи на отдельных строках.



Количество элементов или записей: от 0 до 100.

Для B и C числовые значения и порог: от -1000 до 1000.

В D каждое поле содержит от 1 до 200 символов ASCII

без пробелов по краям.



\### Результат

EMPTY — пустой результат.

INVALID — недопустимые входные данные.



\### Сборка и запуск

Пример для части A:

```bash

g++ -std=c++11 A.cpp -o A

./A

```

Для остальных частей замените A на B, C или D.
